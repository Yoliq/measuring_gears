# mesuiring_gears
Repository to handle all code regarding thesis which is about automatization of measuring load on mechanical gears.

For freshly installed RPi use: 

(in desired folder):
 git clone https://github.com/Yoliq/measuring_gears.git 

then install required libraries:
 sudo apt install python3-tk python3-pil python3-matplotlib python3-pandas python3-serial python3-opencv

Repository contains:
* GUI
* IRC library
* Lidar library
